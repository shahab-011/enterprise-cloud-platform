# Security policy

This repository is a local-only engineering demo, not a production service. Do not submit real
credentials, customer data, or private infrastructure details.

For an issue in the demo, open a private report through the repository's configured GitHub
security reporting process when available. Do not publish exploit details or secrets in a public
issue. No private reporting channel is configured in this local workspace.

See [docs/security-review.md](docs/security-review.md) for implemented safeguards, review steps,
and explicit production-readiness gaps.
